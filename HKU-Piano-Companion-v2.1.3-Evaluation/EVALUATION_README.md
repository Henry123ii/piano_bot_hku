# Evaluation edition

This is an **unofficial experimental Microsoft Edge extension** provided for individual evaluation. It has **no expiration date**. The project author has not granted general permission for redistribution or resale.

The extension uses the v2.1.1-style submission system, **not** the v2.2 Precision Edition. Submission, CAPTCHA and manual-verification timings are fixed internally. There are no timing controls to configure. The built-in targets do not guarantee when HKU receives the request.

Install using `edge://extensions` > Developer mode > Load unpacked, selecting the folder containing `manifest.json`. Use Portal login, then Reservation, or set up weekly bookings. Automatic weekly booking is OFF until enabled. CAPTCHA challenges require manual completion. Review the result in HKU My Reservations.

Edge must stay running and the computer awake. The extension does not include a license server, an expiry check, or usage telemetry. It may contain passive asset provenance information, which is not tied to personal accounts or transmitted to anyone.
