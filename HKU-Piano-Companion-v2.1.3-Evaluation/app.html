Instruction


Save your plan once. For manual use, review each booking. For unattended weekly use, explicitly turn on Automatic weekly booking after reading its confirmation. All dates and times are Hong Kong time, even on a computer abroad.




1
Sign in and save your details
Use Portal login for HKU SSO and 2FA. In Reservation, enter your UID and phone with Remember checked. Read the room rules and tick the agreement once. These settings stay on this Edge profile until you clear them or remove the extension.


2
Choose a one-off booking or a weekly plan
Reservation is for one chosen date. Scheduled booking saves a day, start time and room; each row lasts one hour. The next two weeks and their release times are calculated for you. Saving a row by itself does not start a booking. If Automatic weekly booking is enabled, each eligible future occurrence is authorized to run without another confirmation.
Release is calculated as the slot end minus six days, following the project owner's rule. Example: Tuesday 11:00–12:00 releases the previous Wednesday at 12:00, not 11:00. Check HKU if its release policy changes.


3
Review a due slot and confirm once
In manual mode, a reminder is scheduled 30 minutes before release. Aim to start 5 minutes before. In the run timetable, click the dated run time, check the details, then Confirm live booking. When Automatic weekly booking is ON, future eligible sessions run without this manual step. An already-released slot can be attempted immediately after confirmation; availability is not guaranteed.
Live booking is the default. For a first rehearsal, explicitly tick Test only before confirming: it prepares the form but never clicks Create. Only one Create attempt can run at a time. A dedicated Edge booking window stays open after confirmation.


4
Leave the dedicated booking window open and respond to CAPTCHA
The form opens 60 seconds before release; typing aims to finish before CAPTCHA, allowing for loading and browser overhead. Saved or prefilled details are cleared, freshly typed with randomized 60-150 ms character pauses, committed and checked. Only then is CAPTCHA requested at its preset time. After verification, Create is attempted once at or after the target. Slow loading can still make it late; typing is never skipped or aborted solely to meet its time target.


5
Read the actual result
The response box shows the portal's message. A click or HTTP 200 is not a confirmed reservation. Check My Reservations if the outcome is unclear. The planner remembers attempted slots and will not silently retry them. Use Reset only after checking HKU.




CAPTCHA needs a person
VPN or shared-network activity, and repeated use in a short period, may lead to additional reCAPTCHA verification. Randomized typing does not guarantee avoidance. If a challenge appears, the companion shows a warning, requests a notification and tries to bring the booking tab forward. You must solve it manually in the HKU tab.
During typing, leave that booking tab untouched. You can use your original Edge window, but keep the dedicated booking window open and do not let the computer sleep. System settings can mute notifications or prevent focus changes.


Saved data and permissions
Personal details, agreement consent, weekly sessions and their attempt statuses are stored locally. Nothing is sent to a project-owned server. Clear saved details removes personal details, agreement consent and logs; weekly rows stay until you delete them. Reinstalling or removing extension data can erase all saved settings.
The debugger permission provides real keyboard input only on the confirmed HKU booking tab. The alarms permission schedules reminders and, only when you explicitly enable Automatic weekly booking, unattended weekly booking starts. An alarm cannot wake a sleeping computer. The companion may close after arming a dedicated booking window. When automatic weekly booking is enabled, alarms may start new booking windows with the companion closed if Edge remains running; sleep and browser shutdown interrupt real-time execution.


Safe timing and limitations
The form must open before CAPTCHA, and typing must be verified before CAPTCHA is requested. Submission and CAPTCHA targets are managed automatically. Slow loading or unusually long details can cause lateness; the extension reports this without skipping typing. Browser stalls, network delays, changed HKU pages, session expiry and CAPTCHA can still delay or prevent a booking; no extension can guarantee a slot. No repeated server refreshes, bulk booking or automatic submission retries are made.
Changing room/date/time invalidates the previous selection. Overnight one-hour sessions use the next day's end date. This tool is unofficial and its release calculation is based on the user's supplied rule, not an independent policy verification.
