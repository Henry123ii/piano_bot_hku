HKU Piano Companion
v2.1.3

Separate Edge booking windows, optional automatic weekly reservations, login checks, CAPTCHA alerts and booking-result notifications.

Update from an earlier version

Finish or cancel any running booking first. Extract this package and copy its contents into your existing extension folder, including runner.html, runner.js, auto.js, and auto-backend.js. Replace the old files.

Visit edge://extensions, press Reload, refresh any HKU tabs, and reopen the companion. Updating the same installed folder should retain locally saved schedules and preferences; removing and reinstalling may not.

First installation

In Edge open edge://extensions, enable Developer mode, select Load unpacked, and choose the extracted folder containing manifest.json. Use the extension icon to open the companion.

Do not open app.html directly as a normal webpage. Approve extension permissions only if you trust the local source code.

Get started

  1. Click Portal login and complete HKU SSO/2FA.
  2. In Reservation, enter your details, enable Remember, and read/accept the room agreement.
  3. For one-off reservations, review the slot and select Confirm & arm. A separate Edge window runs that specific attempt. Closing the original companion does not stop it.
  4. For a safe rehearsal, explicitly select Test only. This never clicks Create.
  5. For weekly sessions, open Scheduled booking and save your weekly hour and room. Automatic weekly booking is OFF by default.
  6. Optionally enable Automatic weekly booking and accept the one-time confirmation. Each future eligible dated session can then run without another confirmation, provided Edge is running and your computer is awake.

What happens in automatic weekly mode?

  • 30 minutes before release: checks whether the HKU session is valid. If not, it requests a notification and opens the login page.
  • 90 seconds before release: opens a dedicated Edge booking window, with the form opening target set 60 seconds before release.
  • Before release: retypes the form details and requests the reCAPTCHA checkbox. Interactive challenges require manual solving.
  • At the scheduled submission time: requests one Create click if the form and CAPTCHA are ready. Submission and CAPTCHA timings are preset and require no configuration. Afterward the app requests a result notification.

Do not close the dedicated window or let your laptop sleep. A click, or HTTP 200, does not guarantee a confirmed reservation. For ambiguous results, inspect HKU My Reservations before retrying.

Turning automatic mode OFF stops future runs, not an already-running window.
